# KRI report and extracted evidence

This directory retains one complete source report:

- [20181205_SWTS_Main_Book.pdf](20181205_SWTS_Main_Book.pdf) — Khazanah Research Institute (2018), *The School-to-Work Transition of Young Malaysians*.
- [section_evidence.json](section_evidence.json) — source URL, retrieval details, relevant page references and the claims contextualised by the notebook.

The report was retrieved from KRI on **3 October 2026**. Its copyright page states a **CC BY 3.0** licence.

Relevant locations:

- **Chart 2.3 and printed page 28:** weighted TVET participation by ethnicity. Visual 1 instead calculates unweighted sample distributions from `SWTS_InSchool.csv` because the released CSV has no survey-weight field.
- **Table 6.7 and printed page 239:** public-sector maximum salary offers by qualification. Visual 2 shows individual valid responses and unweighted summaries for A1 = 3. Their export labels are unconfirmed; the comparison does not establish which category corresponds to the report's public-sector row.

The notebook uses the report for context and does not parse it at runtime. The charts are independent adaptations; KRI did not create or approve them.
